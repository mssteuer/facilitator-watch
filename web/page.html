How to read the evidence

We keep each response exactly as received, including fields we don’t understand. Network IDs are never rewritten.

We only read declarations. Nothing about payments, settlement or discovery is tested, and first seen is just when we first noticed something.

A failed check never proves removal. Only after three valid responses leave something out do we mark it not advertised.
